1. Extract ZIP
2. Copy:
   streamlit_app_upgrade16_failure_prediction.py

   into your PHARMA_PROJECT folder

3. Rename it to:
   streamlit_app.py

4. Replace your current streamlit_app.py

5. Restart:
   streamlit run streamlit_app.py

6. Login:
   admin / admin123
