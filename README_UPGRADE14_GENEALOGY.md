## Installation

1. Extract ZIP
2. Copy:
   streamlit_app_upgrade14_genealogy.py

   into your PHARMA_PROJECT folder

3. Rename to:
   streamlit_app.py

4. Replace current file

5. Restart:

   streamlit run streamlit_app.py

6. Login:
   admin / admin123
