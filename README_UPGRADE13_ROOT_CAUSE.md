# Upgrade 13 — AI Root Cause Investigation Engine

## Install
1. Extract ZIP.
2. Copy `streamlit_app_upgrade13_root_cause.py` into your PHARMA_PROJECT folder.
3. Rename it to `streamlit_app.py`.
4. Replace the old file.
5. Restart: `streamlit run streamlit_app.py`
6. Login: `admin / admin123`

## Test
Open `AI Root Cause Investigation` tab.

Expected:
- batch selector
- investigation priority
- AI confidence
- probable root causes
- contributing process parameters
- corrective actions
- preventive actions
- downloadable report
- audit trail recording button
