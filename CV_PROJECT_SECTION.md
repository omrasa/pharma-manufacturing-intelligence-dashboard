# CV Project Section

## Pharma Manufacturing Intelligence Platform

Built an AI-assisted pharma manufacturing intelligence platform using Streamlit, FastAPI, PostgreSQL, Pandas, Plotly, OpenAI API, LangChain, ChromaDB, ReportLab, and Docker.

### Key Achievements

- Developed an end-to-end manufacturing intelligence dashboard for batch monitoring, deviation detection, QA/CAPA workflows, and release decision support.
- Implemented AI modules for root cause investigation, deviation reporting, process optimization, equipment monitoring, batch failure prediction, and manufacturing copilot support.
- Built a RAG-based QA assistant using LangChain and ChromaDB to retrieve GMP/CAPA knowledge and support investigation questions.
- Added enterprise-style login, audit trail, batch genealogy, PDF reporting, Docker deployment files, and cloud-readiness documentation.
- Designed the project to demonstrate pharma digitalization, manufacturing intelligence, AI-assisted QA, and data-driven process improvement.
