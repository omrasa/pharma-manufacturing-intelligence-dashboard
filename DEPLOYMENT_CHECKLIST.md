# GitHub Upload Checklist

## Step 1 — Create GitHub Repository

Suggested repository names:

- pharma-manufacturing-intelligence-platform
- pharma-ai-manufacturing-dashboard
- pharma-manufacturing-analytics

Repository visibility:
- Public (recommended for job search)

---

## Step 2 — Install Git

Mac:

```bash
brew install git
```

Verify:

```bash
git --version
```

---

## Step 3 — Initialize Git

Inside your project folder:

```bash
git init
```

---

## Step 4 — Connect Repository

Replace YOUR_REPOSITORY_URL:

```bash
git remote add origin YOUR_REPOSITORY_URL
```

---

## Step 5 — Add Files

```bash
git add .
```

---

## Step 6 — First Commit

```bash
git commit -m "Initial enterprise pharma manufacturing platform"
```

---

## Step 7 — Push to GitHub

```bash
git branch -M main
git push -u origin main
```
