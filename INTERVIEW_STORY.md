# Interview / CV Story

## One-Line Project Description

Built an AI-assisted Pharma Manufacturing Intelligence Platform using Streamlit, FastAPI, PostgreSQL, Plotly, OpenAI, LangChain, ChromaDB, and Docker to support batch monitoring, deviation detection, QA/CAPA workflows, RAG-based knowledge assistance, predictive maintenance, and audit traceability.

## 30-Second Interview Pitch

I built a pharma manufacturing intelligence platform that simulates how batch data can be monitored and used for QA decision support. The system connects a FastAPI backend and PostgreSQL database to a Streamlit dashboard, where users can monitor batches, detect deviations, generate CAPA recommendations, create AI-assisted deviation reports, ask RAG-based QA questions, and track actions in an audit trail. I also added live monitoring, predictive maintenance, role-based login, and Docker deployment to make it look closer to a real enterprise manufacturing application.
